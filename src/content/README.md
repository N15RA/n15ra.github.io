# 內容資料（社團可自行編輯）

這些資料**每筆一個 JSON 檔**，放在 `src/content/<分類>/` 資料夾下，檔名即該筆的 `id`。
由 `src/content.config.ts` 以 Zod 驗證，build 時若格式錯誤會直接失敗。**新增一筆**＝在對應
資料夾新增一個 `.json`，不必動任何 `.astro` 元件。顯示順序由各筆的 `order` 欄位決定
（數字大者在前／較新），與檔名或資料夾順序無關。

> 「一筆一檔」是架構選擇：讓 Sveltia CMS 以每筆獨立頁面編輯（巢狀的 courses/officers 尤其
> 清楚）、git diff 以單筆為單位、且為 Decap/Sveltia 通用結構（CMS 導入見後續）。

| 資料夾             | 內容                             | 來源 / 狀態                                                                                                                                                                                                                                                                       |
| ------------------ | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `history/*.json`   | 沿革年表（2006–2014）            | **真實**，取自 old-website `history.html`                                                                                                                                                                                                                                         |
| `events/*.json`    | 最新消息 / 活動 / 合作           | **真實**：Enlightened / Hackathon 取自 NISRA KKTIX（2014–2025）；合作項目沿用夥伴資料                                                                                                                                                                                             |
| `semesters/*.json` | 各學期社課（每檔含 `courses[]`） | **取自 old-website 學期頁**。`desc`＝卡面精簡整合版；`detail`＝點卡片彈窗的完整逐字原文（曾精簡者補上，無差異者免填）。106-1 / 106-2 / 107-2 含日期與講師；108-1 僅標題與簡介（舊站即無）。更早學期當年無線上社課紀錄。                                                           |
| `members/*.json`   | 歷屆幹部（每檔含 `officers[]`）  | **真實**，取自 old-website `members.html`。結構為 `{ cohort, officers[] }`：`cohort`＝學年度/屆數（未知為 `null` → UI 顯示「待確認」佔位），`officers`＝`{ role, name }` 清單（多名以「、」相連）；依 `order` 降冪排列。各屆學年度舊站未明確標示，**待社團確認後填入 `cohort`**。 |

> **內容真實度**：沿革／幹部為舊站真實內容（空白與標點已正規化）；社課卡面為精簡整合版、詳情彈窗為完整逐字原文——故非「逐字搬移」，而是「整理＋完整詳情」。
> 待補：各屆幹部對應學年度、部分社課的日期/講師（舊站即缺）。
> `scaffold: true` 旗標保留供未來標記示意資料；目前所有資料皆為真實。
