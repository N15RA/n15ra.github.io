# 內容資料（社團可自行編輯）

這些 JSON 由 `src/content.config.ts` 以 Zod 驗證，build 時若格式錯誤會直接失敗。
幹部要更新內容，只需編輯下列檔案，不必動任何 `.astro` 元件。

| 檔案             | 內容                   | 來源 / 狀態                                                                                                                                                                                                             |
| ---------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `history.json`   | 沿革年表（2006–2014）  | **真實**，取自 old-website `history.html`                                                                                                                                                                               |
| `events.json`    | 最新消息 / 活動 / 合作 | **真實**：Enlightened / Hackathon 取自 NISRA KKTIX（2014–2025）；合作項目沿用夥伴資料                                                                                                                                   |
| `semesters.json` | 各學期社課             | **取自 old-website 學期頁**。`desc`＝卡面精簡整合版；`detail`＝點卡片彈窗的完整逐字原文（曾精簡者補上，無差異者免填）。106-1 / 106-2 / 107-2 含日期與講師；108-1 僅標題與簡介（舊站即無）。更早學期當年無線上社課紀錄。 |
| `members.json`   | 歷屆幹部               | **真實**，取自 old-website `members.html`；依**會長任期**由新到舊排序。各屆對應的**學年度**舊站未明確標示，**待社團確認後補上**（屆時可把 `range` 改為學年度）。                                                        |

> **內容真實度**：沿革／幹部為舊站真實內容（空白與標點已正規化）；社課卡面為精簡整合版、詳情彈窗為完整逐字原文——故非「逐字搬移」，而是「整理＋完整詳情」。
> 待補：英文內文、各屆幹部對應學年度、部分社課的日期/講師（舊站即缺）。
> `scaffold: true` 旗標保留供未來標記示意資料；目前所有資料皆為真實。
